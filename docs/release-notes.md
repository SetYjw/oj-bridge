OJ Bridge 1.2.0：新增力扣中文站与 LeetCode 国际站支持。

- 在题目页点击“在 VS Code 编程”，自动创建带题号、标题、链接的 .cpp。
- 使用当前站点的官方 C++ 函数/类模板，保留设计题类名，不添加 main()。
- 保存后在力扣网页选择 C++，即可填入网页 IDE 或复制代码；使用网页按钮运行、提交。
- 只写入唯一可见的 C++ 编辑器，不覆盖测试用例或其他语言代码。
- 支持常见题目子页和比赛题目链接；模板获取失败不创建空文件，已有文件仍可重新打开。

升级：解压新版 ZIP，双击 install.cmd；在 edge://extensions 重新加载 OJ Bridge，允许新增的力扣网站访问权限，再刷新题目页。已有目录、命名、模板及代码保留。安装仍使用全局 Windows Python，不创建 venv。
