OJ Bridge

在 OJ 读题，在 VS Code 编程。

本地连接

首次使用请先运行安装包中的 install.cmd，再检测连接。

文档目录会自动识别 OneDrive 和重定向位置。修改目录只影响后续操作，不会搬动已有源码。

重复打开同一道题会沿用原文件。文件名中的非法字符会替换，不覆盖无关同名文件。

题目平台、题号、标题和链接会作为注释自动加在模板前。模板只用于新文件。

日常使用

  1. 打开题目，点击“在 VS Code 编程”。
  2. 编写完成后先按 Ctrl + S 保存。
  3. 回到题目，点击“填入网页 IDE”或“复制代码”。

“填入并提交”会操作站点原有按钮，不代表评测已通过。登录、验证码和评测结果以原网页为准。

优先适配：洛谷、曙梦、AtCoder。另提供 Codeforces、牛客竞赛、LibreOJ、Hydro 适配。站点改版后仍可使用复制代码；各平台的真实页面验证情况请查看安装包中的验证报告。
